Fomoji Authentication Card
Your account's signed identity card — full account info, a unique server-generated pattern, and a signature only Fomoji could have issued.
View / download your card
Requires a fresh device unlock (passkey, password, or PIN) — separate from just being signed in.
Card unlock PIN
An optional quick-unlock secret for the card, separate from your account password.
What "verified" means here: a download carries the card's actual signed data, so it checks out against Fomoji's server. A screenshot only carries pixels — it has nothing to verify, even though it looks identical. No website can detect or block a screenshot itself; what this buys you is that nobody can forge a card that verifies, not that screenshots are prevented.

Recovery
Your one-time recovery code is the only backup door this build has.
Reset with recovery code
Available from the login screen's "Forgot password?" link. Resetting rotates your code automatically.
Go to login
No email-based reset exists — that needs a mail server this build doesn't have. If you lose both your password and your recovery code, there's currently no way back into that account.
Security recommendations
Realistic advice for what this build actually protects.
Store your recovery code somewhere durable and offline — it's shown exactly once and can't be retrieved again.
Use a password you don't reuse elsewhere — hashing protects it locally, but it's still the only thing standing between anyone with browser access and your account.
Sign out on shared or public computers — sessions persist by default until you do.
